# Discord 20MB メディア圧縮ツール

Discordの最新添付制限（**20MB**）に合わせて、動画・画像・音声をブラウザ上で素早く安全に圧縮・最適化するツールです。

---

## 📖 使い方

1. **ファイルを選択**
   - 圧縮したい動画・画像・音声ファイルを画面に**ドラッグ＆ドロップ**（または「ファイルを選択」をクリック）します。

2. **設定を確認**
   - **目標サイズ**: デフォルトで「**20MB（安全設計: 約19.5MB）**」に設定されています。必要に応じて 10MB / 8MB / カスタムサイズに変更も可能です。
   - **解像度・音質**（動画の場合）: 通常は「**自動最適化**」のままで最適バランスになります。お好みで 1080p / 720p / 480p などの指定も可能です。

3. **圧縮を開始**
   - 「**20MB上限で圧縮を開始する**」ボタンをクリックします。
   - エンコード進行状況がリアルタイムで表示されます。

4. **ダウンロード**
   - 完了後、画面上でプレビュー再生やファイルサイズの削減率を確認できます。
   - 「**圧縮済みファイルをダウンロード**」をクリックして保存し、Discordにそのまま添付してください。

---

## 🎯 対応フォーマット

- **動画**: MP4, MOV, WebM, AVI, MKV
- **画像**: PNG, JPEG, WebP, GIF
- **音声**: MP3, WAV, M4A, FLAC

---

## 🔒 セキュリティ・プライバシー

- ファイルは外部サーバーに送信されず、お使いの**ブラウザ内部（端末内）**で直接処理されます。
- 個人動画や機密データも安心してご利用いただけます。
